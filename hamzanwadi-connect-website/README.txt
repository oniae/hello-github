# Hamzanwadi Connect — Website Demo

## Cara menjalankan
1. Ekstrak folder `hamzanwadi-connect-website`.
2. Buka file `index.html` menggunakan Google Chrome / Microsoft Edge.
3. Masukkan email/NIM dan kata sandi apa saja pada halaman login untuk mencoba demo.

## Fitur antarmuka
- Login dan pendaftaran demo
- Beranda/dashboard mahasiswa
- Jadwal kuliah dengan filter hari
- Nilai akademik
- Pengajuan surat (data tersimpan sementara selama halaman aktif)
- Informasi pembayaran UKT
- Profil mahasiswa
- Sidebar responsif untuk desktop dan mobile

## Catatan penting
Ini adalah prototype front-end untuk demonstrasi desain Figma. Login, registrasi, nilai, jadwal, pembayaran, dan pengajuan belum terhubung ke server/database resmi. Data akademik dan tagihan adalah data contoh, bukan data resmi kampus.

## Teknologi
HTML, CSS, JavaScript murni. Tidak memerlukan instalasi package.
